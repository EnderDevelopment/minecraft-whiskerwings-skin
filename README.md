# WhiskerWings: A Minecraft Kemonomimi Skin

WhiskerWings is a high-quality Minecraft player skin that transforms an anime-style male kemonomimi character into an authentic Minecraft skin. This skin features a fluffy white hair, cat ears, blue-violet eyes, a pastel pink and white hoodie, cargo pants, sneakers, and a fluffy cat tail. The skin is designed to be pixel-perfect, compatible with both Minecraft Java and Bedrock editions, and uses clean, carefully placed pixels to recreate the character's appearance.

## Install

1. Download the `kemonomimi_skin.svg` file from the project's GitHub repository.
2. Convert the SVG file to a PNG format using a tool like Inkscape or Adobe Illustrator.
3. Rename the PNG file to `kemonomimi_skin.png`.
4. Place the PNG file in the `skins` folder of your Minecraft game directory.
5. In Minecraft, go to the Skin Customization screen, click on the "Open Skin Folder" button, and select the `kemonomimi_skin.png` file.

## Use

1. Launch Minecraft and go to the Skin Customization screen.
2. Select the `kemonomimi_skin.png` file from the list of available skins.
3. Click on the "Apply Skin" button to apply the WhiskerWings skin to your player character.
4. Enjoy playing with your new kemonomimi skin!
